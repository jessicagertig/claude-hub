## Decisions made (surface to Jessica)

1. **Harvey ball data path**: Extended `AiJobApplicationSummaryStatusSerializer` with `summary_status` and `summary_score_percentage` delegate methods (through the `ai_job_application_summary` association). Also updated the controller eager loading. This avoids a separate API call per nav item but adds 2 fields to every shallow job application payload. The alternative would be a separate bulk endpoint.

2. **ScoringDetail criterion_text → criterionText**: Fixed a latent bug in the cherry-picked component. `allKeysToCamel` deep-converts JSONB column keys, so `criterion_text` would never match. Changed to `criterionText` in both the interface and usage.

3. **PlatoTab empty states**: Replaced the old inline zero states (renderEmpty, renderNoResume, renderFailed, renderProcessing) with `PlatoTabEmptyState` component. Kept the generating shimmer animation separate since PlatoTabEmptyState doesn't have that visual treatment.

4. **Overview callout fallback**: When `integratedRoleAnalysis` is null (old summaries pre-scoring), the overview callout falls back to `summaryText` for the roleFit display.

5. **Removed kebab menu**: The old PlatoTab had a kebab menu icon in the header for non-succeeded states. Removed it since it had no functionality wired to it.

## Convention reminders (from ai-display QA)

- `const t: any = props.theme` (not `const t = props.theme`)
- `||` not `??` (build doesn't support nullish coalescing)
- Optional chaining `?.` IS supported
- No `React.useId()` (React 16.14) — use module counter
- No `t.poly.*` — use `t.dark ? lightValue : darkValue`
- `t.text.sm` etc are complete CSS declarations, not raw values
- Separate styled components for visual variants, not conditional props
- `let Styled: any; Styled = {};` pattern
- `react-spring` not `@react-spring/web`
- No `text-wrap: pretty`
