# Backend Engineer (Go) — Extracted Criteria

 1. [tier_2] Design, build, and maintain backend services in Go that power our PaaS including APIs, scheduler and orchestrator logic, integrations with cloud providers, and internal tooling.
 2. [tier_2] Work closely with our infrastructure team to integrate with Kubernetes (clusters, deployments, autoscaling) and Terraform (infrastructure as code) across AWS, GCP, Azure and other clouds.
 3. [tier_2] Help architect, deploy, and maintain multi cloud racks and environments inside customers' accounts or in our managed environment.
 4. [tier_2] Collaborate with product and UX teams to deliver features for developers such as improving CLI usage, enhancing CI/CD workflows, enabling marketplace and cloud provider integrations, and creating better observability and logging experiences.
 5. [tier_2] Ensure high reliability, scalability, and security of the platform by implementing monitoring, logging, alerting, rollback capabilities, and multi cloud failover strategies.
 6. [tier_2] Participate in code reviews, mentor others, and help define best practices for backend infrastructure, Go services, and cloud deployments.
 7. [tier_1] Strong programming experience in Go (Golang) for production backend systems.
 8. [tier_1] Solid understanding of Kubernetes including cluster design, deployments, autoscaling, service mesh or networking, and stateful vs stateless workloads.
 9. [tier_2] Experience working with Terraform or a similar IaC tool to define and manage infrastructure across cloud providers.
10. [tier_2] Hands on experience in one or more major cloud platforms such as AWS, GCP, or Azure including managing services, network, compute, storage, and security.
11. [tier_2] A good understanding of how a PaaS product works and what it means to abstract away infrastructure for developers while still giving control.
12. [tier_2] Familiarity with CI/CD pipelines, developer tooling, and some exposure to marketplace or cloud provider integrations is a strong plus.
13. [tier_2] Experience publishing or integrating software or solutions on cloud marketplaces such as AWS Marketplace, GCP Marketplace, or Azure Marketplace.
14. [tier_2] Experience working in multi cloud or hybrid cloud environments or customer facing deployment scenarios.
15. [tier_2] Familiarity with system design for high availability, multi region, and multi tenant architectures.
16. [tier_2] Experience with open source projects or distributed systems.
17. [tier_2] Familiarity with monitoring and logging tools and observability such as Prometheus, Grafana, or ELK stack.
