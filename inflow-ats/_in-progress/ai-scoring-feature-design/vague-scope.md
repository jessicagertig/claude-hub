# Vague Scope (non-authoritative reference)

We're building the backend for a unified AI candidate evaluation feature for Inflow ATS. It combines the existing AI summary pipeline (resume extraction, assessment, comparison, role analysis) with a new scoring pipeline (JD criteria extraction, candidate-criteria matching). The scoring pipeline extracts requirements from job descriptions when published, scores each candidate's resume against those requirements, and produces both a numerical score and natural language statements about how the candidate measures up to each criterion. The scoring results feed into the summary's role analysis so they don't contradict each other. The criteria match breakdown with natural language evidence exists so the frontend can display how the candidate measures up to each requirement — but the frontend is not in scope.
