# Fable (claude-fable-5) Independent Review — Plato AI docs

## D1

**Bottom line:** D1 is factually strong: I verified dozens of its copy, state-machine, formula, and gating claims against the actual develop code (empty-state titles, loading steps, regenerate conditions, band thresholds, bulk count/shortfall formulas, toast strings, billing button/badge logic, webhook-return params, policy branches, mailer subjects) and nearly all check out, and it correctly implements the CORRECTIONS.md three-control distinction (Generate review / Generate review now / Run Plato). Eight of the ten prior Opus findings are refuted or substantially addressed in the current text. The real remaining defects: the flagship §3.9 handshake case's setup cannot exercise the awaiting_job_criteria resume path it exists to test (publish-time extraction wins the race), §5.8 tells the tester not to expect a success toast that the server growl actually produces, §6.6's org-deletion case has no UI path at all, and §3.7's threshold verification needs a code-verified annotation since the raw score is never rendered.

## D2

**Bottom line:** D2 is factually solid on everything mechanical — models, providers, tier weights, match values, ×3 multiplier, formula, fit bands, median-of-5 trigger, 5-11 call range, credit-on-success-only, anonymization field list, and prompt guardrails all verify against code — and both prior Opus findings are refuted against the current text.
