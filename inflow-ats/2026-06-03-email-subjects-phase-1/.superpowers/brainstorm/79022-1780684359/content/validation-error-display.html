Subject Validation Error — How should it look?

If a validation error fires on subject, how does the inline display show it? The old FormInput had built-in error styling. The new compact row needs its own approach.

Context

This is nearly unreachable in practice — blur auto-repopulates the default, so subject can't be empty at send time. But defense-in-depth matters, and the form-level error banner alone ("Form Errors: Subject is a required field") without any visual cue on the subject row is confusing.

A. Red label + "Required" text

"Subject:" turns red, value text replaced with italic "Required". Form banner also shows. Clicking the row opens the input to fix it.

C. Skip it — unreachable in practice
