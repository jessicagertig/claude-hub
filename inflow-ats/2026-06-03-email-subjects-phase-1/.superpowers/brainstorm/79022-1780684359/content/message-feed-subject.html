A. Three-dot menu: "Show subject"

Add "Show subject" to the existing dropdown. Clicking it reveals the subject above the body. Menu changes to "Hide subject". Minimal UI footprint — zero visual change until the user asks for it.

B. Tiny "SUBJ" chip in the header

A small bordered chip after the timestamp. Click to toggle subject visibility. When shown, subject appears in a subtle tinted bar above the body. Very compact affordance — discoverable but not pushy.

C. Always visible — ultra-muted line

Subject shown on every message in very light gray between header and body. No interaction needed. Near-invisible unless you look for it. But adds a line to every message, which gets noisy with many messages using the default subject.

Notes

  • Messages with nil subject (historical, pre-feature) would show nothing / hide the affordance entirely
  • "View original" already exists for candidate messages — same expand/collapse pattern could apply here
  • State is not persisted — refreshing the page resets to hidden
