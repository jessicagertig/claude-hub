Empty Subject — What happens on blur?

User clears the subject and clicks away. Two approaches.

1. User clears subject and clicks away →

2. User clicks Send →
Subject is a required field

A. Leave blank — error on Send

Blur with empty → shows "No subject" in gray italic. User hits Send → form error + red subject label. They understand the problem. Click pencil to fix. Original spec behavior.

Subject: Software Engineer at Acme Inc.
Hey, just following up on your application...
Send message
Use template
Subject can't be empty — restored to default

B. Repopulate + toast on blur

Blur with empty → default snaps back immediately + toast explains what happened. User always has a valid subject. Send never fails on subject. Proactive instead of reactive.

Trade-offs

A — Leave blank

  • User sees the consequence of their action
  • Standard form validation pattern
  • Matches original spec behavior

B — Toast

  • Prevents invalid state entirely
  • Explains the auto-fix so user isn't confused
  • Send never blocked by subject
  • But: toast might feel heavy for this small interaction
