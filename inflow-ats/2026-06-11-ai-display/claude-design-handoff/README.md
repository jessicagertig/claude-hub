# Handoff: Plato AI — candidate review tab

## Overview
This adds **Plato** — Polymer's named AI reviewer — as a dedicated tab in the candidate
review view (the nested Job → Applications screen). Plato analyzes a candidate's resume
and produces a *review*: a headline, a domain identity, a "Fit for this role" verdict, and
supporting analysis (notable achievements, relevant experience, gaps, skills). The tab
replaces the old cramped activity-feed summary item; the Overview tab keeps only a small
callout that links into the Plato tab.

Metering: each generated review consumes **1 AI credit**.

## About the design files
The files in `files/` are **design references created in HTML/React-via-Babel** — a working
prototype showing intended look and behavior, **not production code to ship directly**. The
task is to **recreate this design in the real Polymer codebase** using its established
patterns (the actual `@ats`/`@shared` components, Emotion styled-components, `theme.poly.color.*`
tokens, real routing and data). Treat the prototype's inline-style values as the source of
truth for spacing/color/type, and map them onto the real design-system components.

## Fidelity
**High-fidelity.** Final colors, typography, spacing, copy, and interactions. Recreate
pixel-accurately using the codebase's existing components and tokens. All visual values below
are exact (taken from the prototype and the Polymer DS tokens).

## Where it lives
- Route surface: the in-job candidate review view (`JobApplicationsView` / faithful to
  `JobApplicationContainer` + `JobApplicationSidebar`).
- The candidate sidebar (pane 3) tab nav gains one item — **Plato** — below the existing
  Overview / Resume / Messages / Files / Private notes. It is marked with the Plato star chip
  instead of a Feather icon.
- Pane 4 renders the Plato tab content when that nav item is active.
- The Overview tab gets a **callout card** (entry point) directly under "Application received".

## Screens / views

### 1. Plato tab — pane 4 content
Same structural idiom as the other tabs: a `.tab` column → `.tab-title` header bar → a
vertically scrolling body. Body content is centered in a **720px max-width** column with
`22px 28px 56px` padding.

**Header bar (`.tab-title`)**
- Left: the **Plato star chip** (28px square, see Plato mark below) + the word **"Plato"**
  (the tab/feature name — tweakable to "AI summary" in the prototype, but Plato is the chosen default).
- Right: when a review exists, a **ghost Button** "Regenerate" with a `refresh-cw` icon (15px).
  Otherwise a kebab (`more-vertical`, 16px) icon button.

The body switches on review **status** (see State machine). The rich "succeeded" layout, top → bottom:

1. **Provenance line** — `"Generated by Polymer Plato"` + `·` + relative timestamp
   (e.g. "2d ago"). 12.5px, `--text-secondary`, the dot `--neutral-300`. Timestamp uses
   tabular figures (`.poly-tnum`). 18px bottom margin.
2. **Stale banner** (only when the review is out of date) — see States.
3. **Headline** — `<h1>`, 23px / line-height 1.28 / weight 600 / letter-spacing −0.02em /
   `--text-loud`, `text-wrap: pretty`. Margin `0 0 10px`. (The headline is a short one-line
   gist; in the prototype it comes from `summary_text`'s headline field.)
4. **Domain label** — primary · secondary domain from `assessment` (e.g.
   "Quality assurance • Test automation"). Each label 13px/weight 500; primary `--text-loud`,
   secondary `--text-secondary`. Separator is a **3px filled circle**, `--neutral-500`
   (NOT a `·` glyph — the glyph reads too faint). 16px bottom margin.
5. **Fit for this role** — the lead "nugget" card. A bordered card (1px `--border`, 9px radius,
   `16px 20px 20px` padding) with a **3px accent-gradient bar** down the left edge
   (`var(--accent-gradient)`, absolutely positioned, full height). Header row: a 15px Plato
   star (in `--neutral-700`) + the label **"Fit for this role"** (13.5px/600/`--text-loud`).
   Body text 15px / line-height 24px / `--text-primary`. Sourced from `role_analysis`. 24px
   bottom margin.
6. **Notable achievements** — eyebrow `"Notable achievements"` (see `.poly-eyebrow`) over a
   list. Each item: a 15px `award` Feather icon (`--neutral-700`) + text (14px/lh 21px/
   `--text-primary`). Sourced from `assessment.standout_accomplishments`. Gap 9px between items.
7. **Relevant experience** — eyebrow `"Relevant experience"` + a paragraph (14.5px/lh 23px/
   `--text-primary`, max-width 66ch). Sourced from `applicable_experience`.
8. **Gaps to probe** — eyebrow `"Gaps to probe"` + paragraph (same prose style). Sourced from
   `gaps`.
9. **Skills** — eyebrow `"Skills"` + a wrapped chip cloud. Each chip: 13px/lh 20px, 1px
   `--chip-border`, 4px radius, `3px 10px` padding. **Key skills** (from
   `assessment.key_skills`) render emphasized: text `--text-loud`, fill `--neutral-100`; they
   are sorted to the front. Non-key skills: text `--text-primary`, transparent fill. Sourced
   from `structured_data.skills`.
10. **Footer disclaimer** — 30px top margin, 14px top padding, 1px `--divider` top border. An
    `info` icon (13px, `--neutral-400`) + `"Plato can be wrong. Always confirm against the
    resume before deciding."` (12px, `--text-placeholder`).

> NOTE: an experience-by-domain bar chart (`months_by_domain`) was deliberately **removed** —
> the source numbers double-count overlapping time and imply false precision. Do not add it back.
> The dormant `AiExpStrip` function may remain in code but is unused.

### 2. Overview callout — entry point (pane 4, Overview tab)
A clickable card placed directly under the "Application received" feed row, linking into the
Plato tab. Class `.ai-callout` (see `ai.css`): flex row, 13px gap, 14px/16px padding, 1px
`--border`, `--radius-md`, `--surface-card`, with a **3px accent-gradient left bar**
(`.ai-callout-bar`) and a small connector tick below it. Border darkens to `--border-hover`
on hover. Contains: a 32px Plato star chip, a title + subtitle column, and a right-aligned
CTA (`View` or `Generate` + `chevron-right`).

Copy is **state-dependent** (this is the key UX point — the "has a review" and "no review yet"
states must read differently):
- **No review yet:** title **"Ask Plato to review this candidate"**, sub
  "Plato reads the resume for role fit, experience, skills and gaps.", CTA **Generate**.
- **Has review:** title **"Read what Plato thinks about this candidate"**, sub = the review
  headline, CTA **View**.
- **Stale:** title **"Plato's review is out of date"**, sub = headline, CTA **View**.
- **No resume:** title **"Plato needs a resume"**, sub "Add one to this candidate and Plato can
  review them.", CTA **View**.
- **Failed:** title **"Plato couldn't finish"**, sub "No credit was used — open to retry.", CTA **View**.
- **Generating:** title **"Plato is reading the resume…"**, sub "This will be ready in a moment.", CTA **View**.

## State machine (review status)
The review object carries a `status`. Map exactly:

| status | Plato tab body | Notes |
|---|---|---|
| `succeeded` | full rich layout (above); if `stale` also show stale banner | the hero |
| `pending` / `in_progress` / `extracted` | **Generating** — shimmer skeleton + animated dots pill, "Plato is reading the resume and writing the summary…" | |
| `textract_processing` | **Processing** — "Plato is waiting on the resume" zero-state, no action (auto-advances) | resume file still being read |
| `failed` | **Failed** — "Plato couldn't generate the summary", "No credit was used.", primary **Try again** + "Uses 1 credit" below | no credit charged |
| `none` / no review, has resume | **Empty** — "Plato hasn't reviewed this candidate yet", "Plato will analyze the resume for role fit, relevant experience, skills, and gaps.", primary **Generate summary** + "Uses 1 credit · N remaining" below | |
| `none` / no resume | **No resume** — "Plato needs a resume", "Plato reviews a candidate from their resume. Add one to this candidate to get started.", no generate action | |

### Empty / Failed action layout (important)
The credit hint must be **stacked below** the centered button (column, 8px gap, centered) —
NOT inline beside it (inline breaks the button's optical centering). Hint copy:
"Uses 1 credit · N remaining" (empty) / "Uses 1 credit" (failed). Tabular figures on the number.

### Generating skeleton
Pill: rounded-999, `--well-canvas` bg, three **pulsing dots** (`.ai-dot`, 5px, `--neutral-500`,
staggered 0.16s delays) + label. Below: shimmer bars (`.ai-shimmer`) standing in for headline
(22px), paragraph lines (13px), a block (84px), and chip row. Shimmer = animated
`linear-gradient(90deg, --neutral-100, --neutral-200, --neutral-100)` sweeping 1.4s. See `ai.css`.
**Both animations must respect `prefers-reduced-motion: reduce` (disable).**

### Stale banner
Row: `--well-canvas` bg, 7px radius, `10px 12px` padding. `alert-triangle` (15px,
`--text-secondary`) + "The resume changed after Plato wrote this summary." + a right-aligned
text button "Regenerate · 1 credit" (`refresh-cw` 13px).

## Plato mark (the star)
The AI marker. See `files/PlatoMark.jsx`. Default variant **`"sparkle"`** = Lucide's single
4-point star (stroked, 2px). Two more variants ship in the component and should be kept as
selectable options: `"sparkles"` (big star + dot filled, plus stroked) and `"wand"` (Lucide
wand-sparkles).
- `<PlatoMark size={n} />` — the glyph, inherits `currentColor`.
- `<PlatoChip size={n} radius={n} />` — the glyph centered in a **pink→peach accent-gradient**
  rounded square (`var(--accent-gradient)`, `--neutral-900` glyph, inset 1px hairline). This is
  the premium Plato marker used in the tab header (28px), nav item (22px, 6px radius), and
  Overview callout (32px).

## Interactions & behavior
- **Nav:** clicking the Plato sidebar item sets the active tab to the Plato pane. Clicking the
  Overview callout navigates to the Plato tab (`setTab("ai")`).
- **Generate / Regenerate / Try again:** in production these trigger the review generation
  request (spend 1 credit) and move status to `in_progress` → `succeeded`/`failed`. In the
  prototype they are inert.
- **Per-candidate dot** in the list (optional, present in prototype): a tiny status dot hints
  review state (ready = accent, working = neutral, etc.).
- Transitions: 0.2s ease on background/border/color (DS standard). No bounces.

## State management
- `selectedId` — which candidate is open.
- `tab` — active sidebar tab (`"overview" | "resume" | "messages" | "files" | "notes" | "ai"`).
- Each candidate carries an `aiSummary` (the review object) — see Data model. In production
  this is fetched per candidate; null/absent means "no review yet".
- The component exposes three configurable options (driven by a Tweaks panel in the prototype —
  build them as real props/config, with the current values as defaults):
  - `mark` — Plato star variant: **`sparkle`** (default) | `sparkles` | `wand`.
  - `name` — feature/tab label + provenance voice: **`Plato`** (default, → "Generated by
    Polymer Plato" and the Plato-voice copy) | `AI summary` (→ "Generated by Polymer AI",
    neutral copy).
  - `showCredits` — whether the "Uses 1 credit…" hint shows under generate/retry actions:
    **on** (default).
  All Plato-voice strings have a corresponding neutral (`AI summary`) variant — see `ai-tab.jsx`.

## Data model (review object)
Normalized from the DB record. Raw shape is in `files/samples.js` (real generated examples).
Key fields (snake_case in DB → camelCase in prototype):

```
status                     pending|in_progress|extracted|textract_processing|succeeded|failed|none
stale                      bool — resume changed after generation
headline                   string — one-line gist
summary_text               string — (no longer rendered as a paragraph; headline carries the gist)
structured_data:
  name, email, phone, location, links[]
  skills[]                 → Skills chips
  total_months_experience  (NOT shown — unreliable)
  months_by_domain {}      (NOT shown — double-counts; removed by design)
  role_analysis            → "Fit for this role"
  applicable_experience    → "Relevant experience"
  gaps                     → "Gaps to probe"
  overlap_summary          (NOT shown — redundant with role_analysis)
  work_experience[], education[], certifications[]
  assessment:
    primary_domain.name,
    secondary_domain.name  → domain label
    key_skills[]           → emphasized skill chips
    standout_accomplishments[] → "Notable achievements"
    career_narrative       (available, not currently shown)
    experience_classifications (available, not currently shown)
```

Copy intentionally avoids the word "summary/summarize" in Plato-voice strings — Plato produces
a *review*, not just a summary.

## Design tokens (all from the Polymer ATS DS)
Use the real `theme.poly.color.*` aliases; the prototype uses these CSS vars:
- **Text:** `--text-loud` (near-black), `--text-primary`, `--text-secondary` (neutral-600),
  `--text-placeholder`.
- **Surfaces / lines:** `--canvas`, `--surface-card`, `--well-canvas` (neutral-100),
  `--border` (neutral-200), `--border-hover` (neutral-400), `--divider`, `--chip-border`.
- **Neutrals:** `--neutral-100/150/200/300/400/500/700/900`.
- **Accent:** `--accent-gradient` = `linear-gradient(120deg, #FBD7FF 10%, #FFDEC1 90%)` —
  reserved for the Plato chip, the Fit-card left bar, and the callout left bar. Never a flat
  fill behind text.
- **Radii:** xs 4 / sm 5 / md 7 / lg 13 (`--radius-md` for cards/callout).
- **Type:** Suisse Intl (Inter fallback), weights 400/450/500/600. Sizes per component above.
  Eyebrows use `.poly-eyebrow` (small uppercase tracked). Numbers use `.poly-tnum`.
- **Icons:** Feather (`award`, `refresh-cw`, `alert-triangle`, `alert-circle`, `file-text`,
  `info`, `chevron-right`, `more-vertical`, `zap`), 2px stroke, `currentColor`.
- **Buttons:** the DS `Button` (primary black / secondary / ghost).
